# Chile Privacy Operations

Internal professional application for operationalizing Chilean private-sector personal-data-protection work.

## Product direction

The product is designed in two stages:

1. Stage 1: navigable operational manual, characterization and decision-support map.
2. Stage 2: persistent client-specific operational roadmap with evidence, documents, history and auditable execution.

The legal and operational architecture is maintained through canonical repository documentation.

## Repository governance

Before making substantive changes, read:

- `AGENTS.md`
- `docs/IMPLEMENTATION_STATUS.md`

Load additional canonical documents only as required by the current task.

## Important

This repository is not the authority for independently interpreting or updating Chilean law.

Approved legal content is supplied through controlled domain specifications.

Coding agents must implement that content without inventing new legal obligations.
